# Release Notes — FinUp v2.3.2 / Web Revision 1

Tanggal rilis: 31 Juli 2026

## Web

- Kebijakan sesi browser yang lebih aman dan pilihan Tetap masuk.
- Validasi backup menyeluruh serta backup otomatis pra-impor.
- Updater admin-only, rate limiting token, deteksi file tidak terlacak, dan pembaruan runtime updater otomatis.
- Pembersihan menu dan teks Android-only dari tampilan web.
- Header keamanan Nginx dan kontrol cache diperkuat.

## Android

- Version Name dinaikkan menjadi 2.3.2 dan Version Code menjadi 30.
- Modul validasi backup yang sama dengan Web ditanam di APK/AAB.
- Login startup fix dan Enter/Done dari v2.3.1 tetap dipertahankan.
- Package dan sertifikat signing resmi tidak berubah.
