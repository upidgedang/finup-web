# FinUp Web v2.3.7

## Kesetaraan pratinjau dan file PDF

FinUp v2.3.7 membuat satu paket PDF saat pratinjau dibuka. Tampilan pratinjau dirender dari operasi gambar paket tersebut dan tombol Simpan PDF menyimpan byte PDF yang sama. Karena itu jumlah halaman dan isi setiap halaman tidak dirender ulang atau dihitung dengan algoritme terpisah.
