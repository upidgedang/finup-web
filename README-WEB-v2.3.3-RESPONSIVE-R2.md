# FinUp Web v2.3.3 — Responsive Revision 2

Revision 2 memperbaiki tampilan adaptif tanpa mengubah data, Firebase, updater, atau APK.

## Perangkat dan orientasi

- Ponsel kecil dan ponsel lebar
- Tablet portrait dan landscape
- Desktop/laptop hingga layar lebar
- Mode portrait dan landscape
- Split-screen/foldable dengan lebar sangat sempit

## Perbaikan utama

- Tidak ada scroll horizontal pada layout utama.
- Grid menyesuaikan jumlah kolom berdasarkan ruang yang tersedia.
- Tablet portrait tidak dipaksa memakai dashboard dua kolom.
- Form, modal, login, lock screen, dan quick-add tetap dapat digulir pada landscape pendek.
- Tombol, daftar, filter, grafik, dan tabel tidak terpotong.
- Header, navigasi bawah, dan FAB dipadatkan pada landscape pendek.
- Zoom browser kembali diizinkan untuk aksesibilitas.
- Keyboard virtual memakai `interactive-widget=resizes-content` pada browser yang mendukung.

## Catatan rilis

Version Name tetap `2.3.3`, Version Code Android tetap `31`, dan Web Revision menjadi `2`.
