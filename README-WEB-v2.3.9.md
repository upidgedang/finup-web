# FinUp Web v2.3.9

FinUp Web v2.3.9 menambahkan header yang tetap terlihat pada Dashboard dan seluruh modul. Halaman fitur seperti Pengaturan, formulir, dan halaman laporan memakai header sticky di dalam kontainer gulir masing-masing. Tinggi header dihitung otomatis untuk mobile, tablet, desktop, portrait, landscape, dan safe area perangkat.
