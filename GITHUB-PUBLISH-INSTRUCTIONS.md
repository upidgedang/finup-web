# Upload FinUp Web v2.3.6 ke GitHub

Gunakan paket `FinUp-Web-GitHub-Repository-CLEAN-v2.3.6.zip`.

1. Ekstrak ZIP.
2. Upload **isi folder hasil ekstrak**, bukan ZIP-nya, ke root repository `upidgedang/finup-web` branch `main`.
3. Pastikan root repository langsung menampilkan `index.html`, `version.json`, `web-adapter-v232.js`, `hardening-v232.js`, `report-period-v234.js`, `report-period-v234.css`, `deploy/`, `firebase/`, dan `tests/`.
4. Jangan upload APK, AAB, keystore, `.env`, token, paket signing, atau source Android privat.
5. Setelah commit tersedia, jalankan update melalui menu FinUp Web atau `sudo bash /var/www/finup/deploy/update-finup.sh`.
