# FinUp Web v2.3.6

FinUp Web v2.3.6 membuat penyelesaian konflik sinkronisasi tidak mengganggu aktivitas pengguna. Konflik overlapping yang diselesaikan dengan strategi cloud-wins tetap diarsipkan, tetapi tidak lagi memunculkan toast merah. Konflik identik selama 24 jam digabung menjadi satu catatan dengan penghitung pengulangan.
