# Release Notes — FinUp Web v2.3.3

- Menambahkan template PDF/cetak profesional dan responsif untuk kertas A4.
- Menambahkan ringkasan keuangan, saldo akun, kategori, transaksi, serta nomor halaman.
- Memperbaiki format CSV agar siap diolah di Excel.
- Menambahkan pengujian struktur PDF, xref, pagination, CSV, dan integrasi updater.
- Mempertahankan keamanan updater, validasi backup, sinkronisasi, serta konfigurasi Firebase v2.3.2.
