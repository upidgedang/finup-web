# FinUp Web v2.3.5

FinUp Web v2.3.5 memperbaiki konsistensi periode laporan dan pagination dokumen A4.

## Perbaikan

- Pilihan periode tidak kembali ke Bulan ini saat pratinjau atau ekspor.
- Snapshot periode yang sama dipakai untuk pratinjau, nama file, CSV, PDF, dan log aktivitas.
- Mode periode disimpan dalam sinkronisasi pengaturan.
- Footer A4 berada di luar area isi tabel.
- Halaman pratinjau diskalakan utuh tanpa reflow pada perangkat mobile.

Lihat `README.md` dan `README-DEPLOY-DEBIAN.md` untuk instalasi dan pembaruan.
